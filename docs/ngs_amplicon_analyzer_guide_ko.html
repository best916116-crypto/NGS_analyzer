AmpliconScope 사용설명서

Amplicon NGS 결과 CSV를 브라우저에서 불러와 heatmap, allele spectrum, QC 요약, SVG/PNG/CSV export를 만드는 도구입니다. 파일은 사용자의 브라우저 안에서만 읽습니다.

1. 준비할 파일

파일필수 여부내용
all_mutation_raw.csv필수reference, read, alignment, read count, ratio, filename이 있는 allele-level table
read_counts.csv필수샘플별 n_aligned_noindel, n_aligned_total
summary.nonX_per_pos.mutations.csv선택위치별 mutation count table
sample_sheet.csv선택샘플명, target, condition, annotation 정보

2. 기본 사용 순서

  1. 분석기를 엽니다.
  2. CSV 파일을 드래그하거나 파일 선택 버튼으로 불러옵니다.
  3. 샘플 수, positions, max mutation %, median reads를 확인합니다.
  4. 계산 기준 reads, target positions, minimum reads, figure layout을 조정합니다.
  5. 필요하면 Samples 탭에서 figure에 표시될 sample 이름을 수정합니다.
  6. Allele spectrum과 heatmap data를 확인합니다.
  7. 필요한 형식으로 SVG, PNG, CSV, Figure Report를 저장합니다.

3. Sample 이름 수정

Samples 탭에서 각 sample의 표시 이름을 직접 입력할 수 있습니다. 이 기능은 figure와 export table에 표시되는 label만 바꾸며, 원본 CSV 파일은 수정하지 않습니다.

  • view 버튼을 누르면 해당 sample의 allele spectrum을 볼 수 있습니다.
  • 라벨 초기화 버튼을 누르면 앱에서 입력한 sample 이름을 모두 되돌립니다.
  • sample_sheet.csv가 있으면 기본 label로 사용할 수 있고, 앱 안에서 다시 고칠 수 있습니다.

4. 계산 기준 reads

mutation %를 계산할 때 어떤 read count로 나눌지 정하는 옵션입니다.

  • Indel 제외 정렬 reads: n_aligned_noindel을 기준으로 계산합니다.
  • 전체 정렬 reads: n_aligned_total을 기준으로 계산합니다.

기본값은 n_aligned_noindel입니다. 좌표는 1-based amplicon position으로 표시됩니다.

5. Figure layout

  • Compact panels (auto): 샘플이 많으면 여러 패널로 나누어 더 짧은 heatmap을 만듭니다.
  • Single long heatmap: 모든 샘플을 하나의 긴 heatmap으로 표시합니다.

Figure export에는 제목과 부제목을 넣지 않습니다. 앱에서 설정한 sample label, position tick, mutation percentage legend만 SVG/PNG에 포함됩니다.

6. 내보내기

  • Figure SVG: 벡터 형식 heatmap을 저장합니다.
  • Figure PNG: 이미지 형식 heatmap을 저장합니다.
  • Heatmap CSV: 위치별 mutation % table을 저장합니다.
  • Figure Report: 사용한 설정과 요약값을 Markdown으로 저장합니다.

7. 데이터 보호

이 앱은 정적 HTML 파일입니다. 로그인, 서버 업로드, 데이터베이스 저장 과정이 없습니다. 개인 실험 데이터나 raw sequencing file은 GitHub repository에 올리지 말고 브라우저에서 직접 불러오세요.
