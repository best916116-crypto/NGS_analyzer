AmpliconScope 홈 분석기 열기

NGS 앰플리콘 Figure 분석기 사용설명서

서버 없이 브라우저에서만 실행되는 static HTML 앱입니다. Amplicon NGS 변이 CSV를 불러와 위치별 변이 히트맵, allele 스펙트럼, QC 표, 검증 체크, figure용 SVG/PNG/CSV/Markdown 리포트를 만듭니다.

1. 데이터 원칙

파일은 브라우저 메모리에서만 읽습니다. 서버 업로드, API 호출, 외부 전송이 없습니다.

raw sequencing file, 개인 실험 CSV, FASTQ, 대용량 결과물은 GitHub에 올리지 마세요.

2. 필수 입력 파일

  • all_mutation_raw.csv: ref, alignment, read, n_reads, ratio, filename
  • read_counts.csv: filename, n_aligned_noindel, n_aligned_total

선택 파일로 summary.nonX_per_pos.mutations.csv, summary.mutations.csv, sample_sheet.csv를 추가할 수 있습니다.

3. 기본 사용 흐름

  1. 분석기를 엽니다.
  2. 처음에는 합성 데모 불러오기로 화면 구성을 확인합니다.
  3. 실제 분석 시 all_mutation_raw.csv와 read_counts.csv를 드래그하거나 파일 선택으로 불러옵니다.
  4. 가능하면 summary.nonX_per_pos.mutations.csv도 함께 불러와 위치별 count 검증을 켭니다.
  5. 샘플명이 어렵다면 샘플시트 템플릿을 내려받아 metadata를 채운 뒤 업로드합니다.
  6. 지표, 분모, 행 표시, 행 정렬, 배경값, 최소 depth를 조정합니다.
  7. QC 배지와 검증 체크 탭을 확인한 뒤 내보냅니다.

4. 주요 설정

  • 지표: 전체 변이 또는 특정 base conversion을 선택합니다.
  • 분모: 기본은 no-indel 정렬 read이며, total aligned read도 선택할 수 있습니다.
  • 행 표시: 개별 샘플, 조건 평균 +/- SD, 조건 중앙값을 선택합니다.
  • 배경값: 대조군 중앙값 차감은 control group을 확인한 뒤 사용합니다.

논문용 figure와 export report의 scientific labels는 영어로 표시됩니다. 예: Intended edits, Target positions, mutation percentage.

5. 내보내기

  • Figure SVG: 히트맵과 선택 샘플 allele 스펙트럼을 하나의 SVG로 저장합니다.
  • SVG: 현재 히트맵만 저장합니다.
  • 멀티패널 SVG: 타깃별 패널을 세로로 쌓은 SVG를 저장합니다.
  • PNG: 빠른 미리보기용 이미지입니다.
  • Heatmap/Allele/QC CSV: 후속 분석이나 그래프 재작성에 사용합니다.
  • Figure Report: 설정, QC, 표시 행, allele, methods 문구를 Markdown으로 저장합니다.
